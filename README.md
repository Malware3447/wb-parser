# wb-parser

Ежедневная проверка поисковой выдачи Wildberries: по списку «SKU;запрос» сохраняет первые 30 товаров каждой выдачи с ценами и показывает, на каком месте стоит наш товар.

Выдачу получает настоящий браузер ([CloakBrowser](https://github.com/CloakHQ/CloakBrowser)): он сам проходит проверку Wildberries, поэтому вписывать в код cookie и токены не нужно.

## Установка

Нужны Go и Node.js 22.12 или новее.

```
cd browser
npm install
```

Сам браузер (около 535 МБ) скачается при первом запуске в `%USERPROFILE%\.cloakbrowser`.

## Запуск

Список товаров лежит в `queries.csv`, по строке «SKU;запрос». У одного SKU может быть несколько запросов.

```
go run ./cmd
```

или двойным щелчком по `run.bat`.

Параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-queries` | `queries.csv` | файл со списком |
| `-out` | `data` | папка для отчётов |
| `-top` | `30` | сколько первых товаров сохранять |
| `-raw` | выключен | сохранять полные ответы Wildberries |
| `-headed` | выключен | показывать окно браузера |

## Что получается

В папке `data` за каждый день два файла, оба открываются в Excel:

- `ДАТА_top.csv` — первые 30 товаров по каждому запросу: позиция, артикул, бренд, название, продавец, цена до скидки и цена продажи, скидка, рейтинг, отзывы, остаток, отметка «наш».
- `ДАТА_summary.csv` — по строке на каждую пару «SKU;запрос»: позиция нашего товара среди первых 100, его цена, минимальная, медианная и максимальная цена топа.

Повторный запуск в тот же день перезаписывает файлы этого дня.

## Ограничения

- Выдача зависит от региона: Wildberries определяет его по IP компьютера, с которого идёт запуск.
- Цена берётся по самому дешёвому размеру товара и не учитывает личную скидку и WB Кошелёк.
- Остаток Wildberries в выдаче обрезает: у большинства товаров стоит одно и то же предельное число.
- Рекламные размещения от обычных не отличаются: признак рекламы в ответе зашифрован.
