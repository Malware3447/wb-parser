# wb-parser

Ежедневная проверка поисковой выдачи Wildberries. В интерфейсе вручную заводятся артикулы (SKU) и прикреплённые к ним поисковые запросы; раз в день по каждому запросу сохраняется выдача, и видно, на каком месте стоит наш товар и какие цены вокруг.

Выдачу получает настоящий браузер ([CloakBrowser](https://github.com/CloakHQ/CloakBrowser)): он сам проходит проверку Wildberries, поэтому вписывать в код cookie и токены не нужно.

## Установка

Нужны Go и Node.js 22.12 или новее.

```
cd browser
npm install
```

Сам браузер (около 535 МБ) скачается при первой проверке в `%USERPROFILE%\.cloakbrowser`.

## Запуск

```
go run ./cmd
```

или двойным щелчком по `run.bat`. Интерфейс откроется на http://127.0.0.1:8080. Пока программа запущена, она сама проверяет выдачу раз в день; если в назначенное время она была выключена, проверка пройдёт после запуска.

Параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-addr` | `127.0.0.1:8080` | адрес интерфейса |
| `-at` | `09:00` | время ежедневной проверки |
| `-tz` | `Europe/Moscow` | часовой пояс расписания |
| `-data` | `data` | папка с данными |
| `-auth` | нет | `логин:пароль` для входа (или переменная `WB_AUTH`) |
| `-base` | нет | путь, под которым интерфейс виден снаружи, например `/wb` |

## Интерфейс

- **Главная** — список товаров: наша цена, статус цены к рынку, индекс, сколько конкурентов дешевле нас, лучшая позиция. Здесь же добавление товара, кнопка «Проверить сейчас» и настройки.
- **Страница товара** — сводка по артикулу, таблица по запросам (показы, позиция в выдаче и без рекламы, медиана первых 10 конкурентов, минимум в топ-3, индекс и его изменение к прошлому дню, самый дешёвый конкурент, позиции по дням) и под ней первые 10 конкурентов по каждому запросу с ценой относительно нашей. Здесь же правка запросов.
- **Страница запроса** — топ-30, топ-50 или топ-100 за выбранный день; наши товары и реклама выделены, показано, кто поднялся и кто опустился.
- **CSV** — выдача за день одним файлом, открывается в Excel.

Запросы вводятся по одному на строку. После «;» можно дописать показы запроса в рекламе («мешки для мусора 30 л;1226»): по ним запросы упорядочены, а общий индекс товара взвешен.

## Как считается

- **Индекс** — наша цена, делённая на медиану цен первых 10 обычных карточек конкурентов. Рекламные карточки и наши собственные товары в расчёт не идут.
- **Статусы** по индексу: ниже 0,90 — переуценка, до 0,95 — чуть ниже рынка, до 1,05 — в рынке, до 1,15 — дороже рынка, выше — сильно дороже. Пороги меняются в настройках.
- **Наша цена** берётся из карточки товара, поэтому она есть, даже когда товара нет в выдаче.
- **Нашими** считаются сам артикул и другие артикулы той же карточки (у них общий номер карточки).
- **Реклама** определяется по полю `logs` в ответе поиска: оно есть только у части карточек и пропадает в сортировках, где рекламы нет. Содержимое поля зашифровано, поэтому ставка не видна, а сам признак — вывод из наблюдений, не из документации.
- **Регион** задаётся в настройках (по умолчанию Москва, код `-1257786`): код подставляется в запросы сайта к API. От региона зависят цены и выдача.

## Выкладка на сервер

```
docker compose up -d --build
```

Контейнер слушает `127.0.0.1:8095` и рассчитан на адрес с префиксом `/wb` (параметр `-base`); наружу его отдаёт nginx:

```
location /wb/ { proxy_pass http://127.0.0.1:8095/; }
```

Данные лежат рядом, в папке `data`.

## Как устроено

- `cmd/main.go` — запуск.
- `internal/web` — интерфейс и расписание.
- `internal/store` — данные в JSON: `data/state.json` (товары и запросы) и `data/snapshots/ДАТА.json` (выдача за день, по 100 товаров на запрос, и карточки наших товаров).
- `internal/parser` — запуск браузерного скрипта и разбор ответа.
- `browser/fetch.mjs` — открывает в CloakBrowser поиск и карточки товаров и забирает ответы API Wildberries.

## Ограничения

- Цена берётся по самому дешёвому размеру товара и не учитывает личную скидку и WB Кошелёк.
- Одновременно идёт одна проверка: бесплатная сборка браузера допускает одну сессию.
